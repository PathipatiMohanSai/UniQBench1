# Data and Code Availability

The public UniQBench repository contains the revised manuscript, available source modules, supplementary analysis scripts, machine-readable result tables, and supporting figures. The primary benchmark cites the OpenML MNIST 784 dataset (dataset 554). The external-validation study uses the UCI Breast Cancer Wisconsin (Diagnostic) dataset (Dataset 17).

The original 432-record MNIST benchmark count is retained from the supplied manuscript. The raw instance-level MNIST prediction snapshot was not included in the supplied manuscript artifacts and is therefore not reconstructed.

The supplementary WDBC experiments, encoding ablation, ten-seed replication, error analysis, sensitivity analysis, and complexity/scaling material are included with their scripts and machine-readable summaries. These additions are explicitly identified as independent validation/replication work rather than byte-level reproduction of the original MNIST runs.
